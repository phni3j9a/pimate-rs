# Pixel 3 / Android #98・#99

修正前は Issue に添付された release 0.2.2 の素材 (`1e81c47` の `74/device/`)。修正後は `c4e23d8` と同じアプリコードの debug。ライト・文字倍率1.0、1080×2160。接続先は loopback の `scripts/android-demo.py`、`adb reverse` を使用。

- **ドロワー:** `(70,1500)→(1000,1500)`。1400ms は修正前は閉、修正後は開。280ms は前後とも開。修正後は同じ1400msで `(180,1200)→(470,1200)` は閉、`→(800,1200)` は開。表内で `(950,670)→(160,670)` すると「備考」「最後のセル」が現れ、逆向きでは「名前」に戻る（ドロワーは閉）。
- **末尾:** `PIMATE_DEMO_DESKTOP_REVIEW=1` の一覧から `/demo/android` を開き、その後は触らず約18秒録画。720×1440、x=69の24×8灰色テンプレートを縦方向に照合。`track.py` が双方の録画をPTS順に全フレーム比較し、最小平均絶対誤差の y を CSV に出力。冒頭のドロワーやアイコン未表示区間における最小値には意味がない。
