# デスクトップ版 0.2.0 の現状監査（Issue #73）

「使えるレベルに達していない」と言われた 0.2.0（`919f51f`）を実際に動かし、使えない点を洗い出したものです。直し方は [README.md](README.md)（画面設計）と [PLAN.md](PLAN.md)（実装の段階）にあります。

## 確認のしかた

- `919f51f` の debug ビルドを、隔離した画面なしの GNOME（一時 HOME・専用の D-Bus と keyring・1440×900 の仮想モニター。`apps/desktop/tests/linux-session.sh` と同じ仕組み）で起動。
- 接続先は模擬 Host（`PIMATE_DEMO_NAME='デモ PC' PIMATE_DEMO_SCREENS=list PIMATE_DEMO_GITHUB_TABLES=1 scripts/android-demo.py`）。
- Mutter の RemoteDesktop でクリック・右クリック・ホイール・キー入力を送り、画面を撮影。画像は `review-assets` ブランチの [`73/audit/`](https://github.com/phni3j9a/pimate-rs/tree/review-assets/73/audit) にあります（下の「撮影」は そのファイル名）。
- コードで確かめた項目は「コード」と書いています。

**確認していないもの:** macOS、本物の Pi、日本語入力（既存の試験が見ている）、端のドラッグによるウィンドウの大きさ変更、プロバイダーのログイン画面、`/resume`・`/tree`・`/fork` の画面、画像の拡大表示、長い会話でのスクロール位置。

重さは **使えない**（その作業ができない・続けられない）／**不便**（できるが遠回り・迷う）／**細部** の3段階です。

## まとめ

1. **Pi が何をしたかが読めない。** ツールの行が「read · 完了」だけで、パスもコマンドも差分も出ない。
2. **止められない・キーボードで動かせない・右クリックが効かない。** デスクトップの基本の操作がほぼない。
3. **何かを開くたびに会話が消える。** モデル・使用状況・セッション・変更レビュー・サブエージェント・GitHub・設定が、すべて会話を丸ごと置き換える1枚の画面になっている。広いウィンドウを使っていない。
4. **部品の見分けがつかない。** ボタンも項目も選択肢もすべて同じ灰色の横長の帯で、主操作がどれか分からない。一方で再起動・更新・停止は赤く塗られている。
5. **ウィンドウとして未完成。** GNOME ではタイトルバーも閉じるボタンもなく、狭めるとヘッダーが崩れ、最大化すると1行が画面の端から端まで伸びる。

## 機能の不足・見つけにくさ（スマホ版と比べて）

「スマホ」は `docs/design/` のモックと `apps/android` の実装です。

| # | 重さ | 問題 |
|---|---|---|
| F1 | 使えない | **停止**がない（O1）。スマホは入力欄に停止ボタンがある |
| F2 | 不便 | **Pi・フォルダの検索**がない。スマホはドロワーの最上段にある。Pi が増えると探せない |
| F3 | 不便 | **通知**がない。設定に「通知」の項目がなく、OS の通知も出さない（コード）。別のウィンドウで作業していると、入力待ちに気づけない |
| F4 | 不便 | **入力欄のモデル表示と使用状況のリング**がない（L11）。モデルの切り替えは別画面 |
| F5 | 不便 | **GitHub** はサイドバーの下の文字「GitHub · Issue / PR」だけで、Pi を選んでいて Host が対応しているときしか出ない。ボタンに見えず、見つけにくい |
| F6 | 不便 | **サブエージェント**の入口は入力欄の上の中央寄せの文字1行だけ。補足の文に見える |
| F7 | 不便 | **はじめての起動**の案内が「左の『リンクを貼り付ける』で…」という文だけ。手順とコマンドは別ページ（はじめての接続ガイド）にあり、スマホのような3手順が最初の画面にない |
| F8 | 不便 | **セッション名の変更**がない（スマホもモックだけ） |
| F9 | 不便 | **送信のタイミング**（割り込む／完了後に送信）と**送信待ちの取り消し**がない（スマホもモックだけ。O9） |
| F10 | 細部 | `@ファイル` のメンションや `/コマンド` が会話の中で色分けされない |

そろっているもの（機能としてはある）: ペアリングと登録の確認、複数マシン、要対応のグループ、質問への回答、モデルと Thinking、使用状況と圧縮、セッション操作、変更レビューと依頼、サブエージェントの一覧・詳細・停止、GitHub の一覧と詳細、新しい Pi、設定（テーマ・文字サイズ・質問ツール）、マシン詳細（更新・再起動・プロバイダー・端末の取り消し・削除）、画像の添付と表示、再接続と未確認メッセージ、PC での操作が必要なときの案内。**足りないのは機能の数より、置き場所と操作の作法です。**
