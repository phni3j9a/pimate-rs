# PiMate Desktop 0.3.0（Linux）

0.2.0 の画面を設計から作り直しました（左に一覧、中央に会話、右に変更・サブエージェント・GitHub）。スマホ版でできることは、TS 版で直した振る舞いも含めてデスクトップでもできます。

- 左の一覧で Pi を選び、中央で会話を続けながら、右で変更・サブエージェント・GitHub を確認できます。差分の行を押すと下書きに引用でき、その場では送信されません。
- Enter で送信、Shift+Enter で改行します。日本語変換中の Enter は確定だけです。Ctrl+K で Pi や操作を検索し、F6 でペインを移れます。Esc は手前の画面を閉じ、会話で作業中なら停止します。送信キーは設定で変更できます。
- 画像を入力欄にドロップして添付できます。Wayland では貼り付けもできます。X11 ではドロップを使ってください。
- OS 通知の代わりにウィンドウタイトルとサイドバーに要対応の件数を表示します。スクリーンリーダー、セッション名の変更、送信済みの割り込みの個別取消には対応しません。

Linux 用の tar.gz（x86_64 または aarch64）を展開し、`bin/pimate-desktop` を起動してください。macOS 版は署名・公証の準備中のため配布しません。
